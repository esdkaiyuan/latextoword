# 文件兼容性与公式识别设计

## 目标

让桌面端公式工作台可以导入主流科研和办公文件，在离线与联网 OCR 之间切换，并将提取结果交给现有公式复核与导入流程。

## 已确认的产品范围

- 源文件：TXT、CSV、TSV、Markdown/MDX、Quarto/R Markdown、reStructuredText、Org、Python/R/MATLAB/Julia/Sage 脚本、LaTeX、HTML、RTF、LTW、JSON、Jupyter Notebook。
- 办公/出版文件：DOC、DOCX、DOCM、PPT、PPTX、PPTM、PPS、PPSX、XLS、XLSX、XLSM、XLSB、ODT、ODP、ODS、EPUB。
- PDF：支持可提取文字层和扫描页 OCR。
- 图片：PNG、JPG/JPEG、TIFF/TIF、BMP、WebP；保留现有图片格式支持。
- 入口：文件多选、文件夹导入、拖放；查看器中可导入单个文件。
- 输入内容依据扩展名、MIME 与文件签名识别，不因错误扩展名而静默按文本读取。

## 识别模式

- 自动：结构化解析优先；扫描页、嵌入公式图像及图片由本地 OCR 处理；用户可切换到联网识别。
- 离线：不发送文件数据；使用本地解析器和 Pix2Text。首次启用时自动下载 uv 管理器、Python 3.12 隔离环境、CPU OCR 依赖和模型，展示当前阶段与进度；缓存准备完成后使用 Hugging Face 离线模式。
- 联网：使用 Mathpix。每次新任务上传前显示文件名、服务商与整份文件上传提示，用户确认后才传输；按其 API 生命周期提交文档、读取 Mathpix Markdown 并清理远程任务。用户在设置中填写 Mathpix app_id/app_key，密钥只经 Electron 主进程和系统加密存储处理。

## 格式解析策略

- 文本/标记格式通过编码检测和既有扫描器处理；保留 BOM、UTF-8、UTF-16 和常见中文编码的正确解码。
- DOCX/PPTX/XLSX、ODT/ODP/ODS、EPUB 作为 ZIP/XML 容器解析文本和原生公式对象；不能映射的公式产生逐文件警告，不能悄悄丢弃。
- RTF 解析文本及常见公式分隔文本。
- PDF 先提取文字层；无文本层或疑似扫描页时转给所选 OCR 引擎。页码需保留为公式来源位置。
- DOC/PPT/XLS 等旧格式优先使用已安装 LibreOffice 转成可解析中间格式；若不可用，Mathpix 在线路径只开放其官方支持的格式，其他格式显示准确的格式/转换提示。
- Mathpix 结果以 MMD/Markdown 进入统一公式扫描，保留文档章节、页码等来源信息。

## 统一结果与界面

解析时保留公式 LaTeX、行内/块级模式和行位置；PDF 文字层带页码标记，OCR 输出保留 Mathpix/Pix2Text 的页面分隔。导入汇报逐文件公式数量与警告；识别候选公式先进入复核窗口，用户可取消错误项后再写入公式集合。

## 安全、隐私与可靠性

- 每次联网任务都需用户显式确认整份文件上传；离线模式不得发起 OCR 网络请求。
- Mathpix 密钥不进入 renderer、项目文件、日志或错误提示明文。
- 文件类型、大小、解压后 ZIP 总大小、条目数及 XML 长度均需有限制；超过限制要说明并让其他文件继续。
- 网络任务支持超时、状态轮询、远端清理与失败重试；uv 可执行文件必须校验 GitHub 发布元数据提供的 SHA-256，环境或模型准备失败时可再次触发。
- 普通文件解析失败隔离在单文件，不阻断批次。

## 不在本阶段承诺

- 手写公式准确率保证；OCR 结果始终需要用户复核。
- XLS/XLSX 单元格中的电子表格计算公式自动改写成 LaTeX 数学公式；此类表达式按工作表文本保留。
- 未经用户确认自动上传、自动覆盖项目、或以 OCR 结果替换原始文件。
